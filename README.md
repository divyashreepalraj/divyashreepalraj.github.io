# 🌐 Divya Shree P — Personal Portfolio

A modern, responsive developer portfolio built with **HTML5, CSS3, and Vanilla JavaScript** showcasing my journey from **UI/UX Designer to Frontend Engineer**.

Designed with performance, accessibility, and clean UI in mind, this portfolio highlights my professional experience, technical skills, GitHub activity, and personal projects while maintaining a premium user experience across all devices.

> This project is built for my **personal portfolio** and is not intended for commercial use.

---

## ✨ Features

-  Interactive Hero Section
-  Custom Cursor
-  Smooth Hover Animations & Micro Interactions
-  Fully Responsive Design
-  Built with Pure Vanilla JavaScript
-  Modern UI inspired by premium product websites
-  Live GitHub Profile Integration
-  Automatic Repository Listing
-  GitHub Contributions Section
-  Scroll-based Navigation
-  Optimized Performance
-  Accessibility Focused
-  Cross Browser Compatible
-  Modern Typography & Glassmorphism Effects
